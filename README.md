# Action Auto-Bot

**Action Auto-Bot** は、店舗のPOSレジやECサイトから出力される「トランザクションデータ（売上履歴）」を読み込み、翌日の接客や営業でそのまま使える **「おすすめのアクション（カンペ）」** を自動生成するデスクトップアプリです。

クラウドにデータをアップロードすることなく、すべてお手元のパソコン内（完全ローカル・オフライン環境）で高速に処理されるため、顧客情報や売上データといった機密性の高い情報も安全に扱うことができます。

## ✨ 主な特徴

- 🔒 **完全オフライン動作**: データを外部（クラウドやAIサーバー）に送信しないため、情報漏洩の心配がありません。
- ⚡ **超高速な分析**: 高速なシステム基盤（Rust）により、数万〜数十万件のデータも一瞬で分析し、結果を表示します。
- 🎯 **現場で使える「カンペ」を生成**: 複雑なグラフや難解な数値ではなく、「美容液セラムを買ったお客様には、導入化粧液もご提案してください（同時購入: 34%）」といった、販売員が今すぐ使える具体的な「指示」を画面に出力します。

## 🚀 使い方

### 1. インストール
GitHub の **Releases** ページより、お使いの環境に合ったインストーラーをダウンロードし、インストールしてください。
- **Windows**: `app_X.X.X_x64-setup.exe` など

### 2. 分析の手順
1. アプリを起動します。
2. 左側のメニューから、分析したい **「対象のCSVファイル」**（売上履歴など）を選択します。
3. （任意）商品名などを分かりやすく表示したい場合は、**「商品マスターCSV」** も選択します。
4. **「ファイルを選択して分析」** ボタンをクリックすると、一瞬でカンペが生成されます！

> 💡 **お試しデモデータ**  
> 初めてお使いの方は、左下の **「(デモ) サンプルデータで試す」** ボタンをクリックしてください。アプリ内に用意されているデモデータを使って、どのようなカンペが生成されるのかをすぐに体験いただけます。

## 📁 CSVデータのフォーマットについて

本アプリは、以下のシンプルな構成のCSVファイルに対応しています。

- **トランザクション（売上対象）CSV**
  - 1列目: `transaction_id`（レシート番号や注文IDなど）
  - 2列目: `item_id`（商品コードや商品名など）

- **商品マスターCSV（任意）**
  - 1列目: `item_id`（商品コード）
  - 2列目: `item_name`（表示させたい分かりやすい商品名）

※ 画面左側の「テンプレートCSVをダウンロード」リンクから、実際のフォーマット例をダウンロードして確認できます。
