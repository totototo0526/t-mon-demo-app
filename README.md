# Action Auto-Bot (t-mon_demo)

Action Auto-Bot は、**オフライン環境で完全動作**する超高速な「購買データ分析 ＆ 行動カンペ自動生成」デスクトップアプリケーションです。

店舗のPOSレジやECサイトから出力される「トランザクション（伝票）CSVデータ」と「商品マスターCSV」をドラッグ＆ドロップするだけで、翌日の営業担当者や販売員がそのまま使える**「〇〇を買う人には××をお勧めする」というカンペ（行動指示）**を瞬時に生成します。

![デモ画面のイメージ](docs/screenshots/demo.png) *(※必要に応じてスクリーンショットを配置してください)*

## ✨ 主な特徴

1. **完全ローカル・オフライン動作**
   - クラウドにデータをアップロードすることなく、セキュアなローカル環境で完結します。機密性の高い購買データの分析に最適です。
2. **超高速・堅牢なRustエンジン**
   - バックエンドにはTauri (Rust) を採用。数百万行規模の巨大なCSVデータも、Rayonを用いたマルチスレッド処理により数秒で分析完了します。
   - 現場のデータにありがちな「欠損行」や「フォーマット異常行」でクラッシュすることなく、エラー行を自動スキップして計算を完遂する堅牢性を備えています。
3. **洗練されたGlassmorphism UI**
   - モダンなダークテーマとGlassmorphismデザインを採用し、分析結果を直感的な「カンペカード」として美しく提示します。

## 🧩 強力な「アドオン（プラグイン）拡張機構」

本ツールの最大の特徴は、本体のソースコード（Rust/TypeScript）を一切改修することなく、**任意の外部スクリプト（Pythonなど）による独自分析ロジックをアドオンとして組み込める**点にあります。

### なぜアドオン機構が必要なのか？
標準のRustエンジンは「同一伝票内での併売分析（Aprioriアルゴリズムの高速化）」というシンプルなユースケースに特化しています。
しかし実際の現場では、「月ごとのバスケットで分析したい」「男女などの顧客属性でセグメントを分けたい」「RFM分析でVIP顧客を抽出したい」といった、**顧客ごとの独自の複雑な要件**が必ず発生します。

これらの要件すべてを巨大なシステムとして本体に作り込むのではなく、**「要件に合わせたPythonスクリプトを1つ書いて `plugins/` フォルダに置くだけ」**で、本アプリのUI上に新しいメニュー（活用シーン）として自動追加されるアーキテクチャを採用しています。

### アドオンの仕組み
1. `app/plugins/` ディレクトリ配下に、任意のフォルダ（例: `python_rfm/`）を作成。
2. `plugin.json` でメタデータ（UIに表示する名前など）を定義。
3. ロジックを記述したスクリプト（例: `analyze.py`）を配置。
   - スクリプトは標準入力（引数）からCSVパスを受け取り、標準出力にJSON形式で結果を返すだけでOKです。

この仕組みにより、既存のPythonデータサイエンス資産（PandasやScikit-learnを用いた高度な機械学習ロジック）を、そのまま美しいデスクトップUI上で動作するアプリケーションへと昇華させることができます。

## 🚀 開発環境のセットアップ

### 前提条件
- Node.js (v18+)
- Rust (cargo)

### 起動方法
```bash
cd app
npm install
npm run tauri dev
```

### パッケージング（ビルド）
Zorin OS (Debian系) 等で単体動作するインストーラーを生成する場合：
```bash
npm run tauri build
```
これにより `app/src-tauri/target/release/bundle/` 配下に実行ファイルや `.deb` ファイルが出力されます。
